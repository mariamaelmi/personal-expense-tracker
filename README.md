
# Personal Expense Tracker

A command-line expense tracking application built using Python.

## About the Project

The Personal Expense Tracker allows users to record their daily expenses, organise spending into categories and review their spending habits.

The application uses JSON to store expenses locally, allowing information to remain available between sessions.

## Features

- Add expenses with descriptions, amounts and categories.
- View all recorded expenses.
- Calculate total spending.
- View spending by category.
- Calculate average expense.
- Automatically save and load expenses.
- Validate user input and handle errors.

## Technologies Used

- Python
- JSON
- VS Code
- Git and GitHub

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python3 main.py
```

The `expenses.json` file is generated automatically when the first expense is saved.
